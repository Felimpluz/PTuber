# PTuber (ProceduralTuber)

PTuber es un motor ligero escrito en Python para avatares 2D procedurales reactivos a la voz.

## Estado del proyecto

🚧 En desarrollo.

## Objetivos

- Animación procedural en tiempo real.
- Física elástica (Squash & Stretch).
- Paralaje 2.5D.
- Reacción al volumen.
- Reacción al pitch.
- Reacción a la colocación vocal.
- Reacción a fonemas.

## Tecnologías

- Python
- Pygame
- NumPy
- SoundDevice
